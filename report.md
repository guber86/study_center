## Этап 2. Очистка и разбиение текста
### Задачи 3–4. Чанкинг и качество фрагментов
1. Способ разбиения текста
Для разбиения текста на чанки создан модуль chunking.py с функцией split_into_chunks(text).

Использован способ разбиения по строкам с помощью split("\n"). Каждый непустой рядок исходного текста становится отдельным чанком.

Перед добавлением фрагмента в список удаляются пробелы в начале и конце строки с помощью strip(). Пустые строки пропускаются.

Функция возвращает список текстовых чанков, который может использоваться на следующем этапе для векторизации.

Чанки № 21 и № 22: возможность получить запись пропущенного занятия и срок её предоставления. Связанные сведения находятся в соседних чанках, поэтому для полного ответа могут потребоваться оба фрагмента.

3. Вывод о качестве чанкинга

Выбран способ разбиения текста по строкам: одно исходное предложение — один чанк.

Этот способ подходит для текущего источника, поскольку каждое предложение содержит отдельный факт. Все 24 предложения сохранены без потери информации.

Ограничение: некоторые связанные сведения находятся в разных чанках. Например, условия получения записи пропущенного занятия и срок её предоставления разделены на два фрагмента.

На следующем этапе необходимо проверить, сможет ли векторный поиск находить все связанные сведения для формирования полного ответа.
