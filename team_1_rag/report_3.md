# Отчёт по личной задаче

## 1. Моя задача

**Vectorization and database preparation**

Моя задача — реализовать векторизацию текстовых данных,
подготовить вектор вопроса и
сохранить связь между вектором и исходным текстовым чанком.

## 2. Подготовка текста

Файл: `preparation/chunking.py`

Реализованы функции:
- `load_text()` — загрузка исходного текста.
- `clean_text()` — очистка текста.
- `split_into_chunks()` — разделение текста на отдельные чанки.

## 3. Подключение модели

Файл: `rag/ingestion/embedder.py`

Используется модель:

`paraphrase-multilingual-MiniLM-L12-v2`

Модель подключена через библиотеку `sentence-transformers`.

Размерность создаваемых векторов — 384.

## 4. Векторизация

Реализованы функции:
- `get_vector()` — создание вектора для текста.
- `get_vectors()` — векторизация всех чанков.

Для каждого чанка сохраняется пара:

`[vector, chunk]`

Таким образом сохраняется связь между вектором и исходным текстом.

## 5. Вектор вопроса

Для подготовки вектора вопроса используется функция `get_vector()`.

Вопрос преобразуется в вектор той же моделью,
которая используется для векторизации текстовых чанков.

Проверена размерность вектора вопроса: 384.

## 6. Сохранение данных

Файл: `rag/ingestion/repository.py`

Результаты сохраняются в:

`database/database.txt`

Каждая строка содержит:
- координаты вектора;
- разделитель `;`;
- исходный текстовый чанк.

## 7. Интеграция и запуск

Файл: `rag/ingestion/ingestion.py`

Объединены все этапы:
1. Загрузка исходного текста.
2. Очистка текста.
3. Разделение на чанки.
4. Создание векторов.
5. Сохранение данных в базе.

Команда запуска из корневой папки проекта:

`python -m team_1_rag.rag.ingestion.ingestion`

## 8. Проверка результата

В ходе проверки получены следующие результаты:
- 24 текстовых чанка обработаны;
- создано 24 вектора;
- размерность каждого вектора — 384;
- связь между вектором и текстом сохранена;
- повторный запуск завершился успешно;
- данные успешно загружены в `database/database.txt`.

**Результат:** векторизация и подготовка базы данных реализованы.
Подготовка вектора вопроса выполняется с использованием той же модели.
