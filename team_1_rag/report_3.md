# Отчёт по блоку 3. Векторизация и подготовка базы данных

## 1. Подключение модели

Файл: `rag/ingestion/embedder.py`

Подключена модель:

`paraphrase-multilingual-MiniLM-L12-v2`

Модель используется через библиотеку `sentence-transformers`.

Размерность создаваемых векторов — 384.

## 2. Векторизация текстовых чанков

Реализованы функции:

- `get_vector()` — создание вектора для одного текста.
- `get_vectors()` — векторизация списка текстовых чанков.

Для каждого чанка формируется пара:

`[vector, chunk]`

Таким образом сохраняется связь между вектором и соответствующим исходным текстом.

## 3. Подготовка вектора вопроса

Для преобразования вопроса в вектор используется функция `get_vector()`.

Вектор вопроса создаётся той же моделью, 
которая используется для векторизации текстовых чанков.

Проверена размерность вектора вопроса — 384.

## 4. Сохранение связи вектора и текста

Файл: `rag/ingestion/repository.py`

Реализована функция `save()`,
которая сохраняет вектор вместе с исходным текстовым чанком.

Формат записи:

`координаты вектора;исходный текстовый чанк`

Данные записываются в локальный файл:

`database/database.txt`

Локальный файл базы данных исключён из Git.
Функция сохранения остаётся частью проекта.

## 5. Интеграция этапов и запуск

Файл: `rag/ingestion/ingestion.py`

Объединены следующие операции:

1. Загрузка исходного текста через `prepare_text.py`.
2. Очистка текста через `clean_text()`.
3. Разделение текста на чанки через `split_into_chunks()`.
4. Создание векторов через `get_vectors()`.
5. Сохранение результатов через `save()`.

Команда запуска из корневой папки проекта:

`python -m team_1_rag.rag.ingestion.ingestion`
