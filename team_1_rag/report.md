# Отчёт по проекту MiniRAG — команда 1

## Этап 1. Анализ исходных данных

- **Название проекта:** MiniRAG — помощник учебного центра.
- **Источник данных:** `source/source.txt`.
- **Предметная область:** учебный центр «Вектор».
- **Количество исходных предложений:** 24.
- **Основные темы:** информация о центре, курсы, расписание, стоимость,
- правила обучения и получения сертификата.

**Вывод:** подготовлен текстовый источник с информацией об учебном центре.
Данные используются для создания базы знаний MiniRAG и 
поиска ответов на вопросы пользователей.

## Этап 2. Подготовка текста

- **Исходный файл:** `source/source.txt`.
- **Загрузка текста:** функция `load_text()`.
- **Очистка текста:** функция `clean_text()` удаляет пустые строки и лишние пробелы.
- **Разделение текста:** функция `split_into_chunks()`.
- **Размер чанка:** 1 предложение (`chunk_size=1`).
- **Количество чанков:** 24.

**Вывод:** исходный текст загружается, 
очищается и разделяется на отдельные чанки для последующего создания embeddings.

## Этап 3. Embeddings и сохранение индекса

- **Модель:** `paraphrase-multilingual-MiniLM-L12-v2`.
- **Количество текстовых чанков:** 24.
- **Форма матрицы embeddings:** `(24, 384)`.
- **Размерность одного вектора:** 384.
- **Файлы индекса:** `embeddings.npy` и `chunks.txt`.
- **Сохранение индекса:** успешно.
- **Повторная загрузка индекса:** успешно.
- **Повторное индексирование:** после повторного запуска осталось 24 чанка и 24 вектора.

**Вывод:** для каждого текстового чанка создан вектор размерностью 384. 
Чанки и векторы сохранены на диске.
Индекс успешно загружается после повторного запуска программы. 
Количество чанков совпадает с количеством векторов.

## Этап 4. Семантический поиск

- **Файл:** `rag/search.py`.
- **Метод поиска:** Cosine Similarity.
- **Векторизация вопроса:** `create_embeddings()`.
- **Выбор результатов:** по убыванию оценки сходства.
- **Количество результатов:** `top_k=3`.
- **Порог сходства:** `threshold=0.35`.
- **Фильтрация:** результаты ниже порога не добавляются в выдачу.
- **Формирование контекста:** `build_context()`.
- **Формирование промпта:** `build_prompt()`.

**Вывод:** реализован семантический поиск по сохранённой базе знаний.
Система преобразует вопрос в вектор, сравнивает его с векторами чанков и
выбирает наиболее подходящие фрагменты для дальнейшей обработки.

### Проверка работы поиска

**Тестовый вопрос:** «Сколько стоит обучение Python?»

Полученные результаты:

1. Стоимость курса «Основы Пайтона» — 48 000 драмов в месяц. Оценка сходства: 0.4594.
2. Стоимость курса «Основы Джаваскрипта» — 52 000 драмов в месяц. Оценка сходства: 0.4493.
3. Обучение оплачивается за каждый месяц вперёд. Оценка сходства: 0.4232.

Все три фрагмента прошли установленный порог сходства `0.35`.

**Результат:** нужная информация о стоимости курса Python найдена.
Контекст и промпт сформированы успешно.

### Формирование контекста

**Файл:** `rag/context_builder.py`.

Реализована функция `build_context(results)`.

Функция:
- проверяет, есть ли результаты поиска;
- извлекает текст каждого найденного чанка;
- объединяет фрагменты в единый контекст;
- возвращает пустую строку, если результаты отсутствуют.

**Результат:** контекст успешно формируется и передаётся в `build_prompt()`
для подготовки запроса языковой модели.
